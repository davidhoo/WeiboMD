# WeiboMD

Chrome 扩展，自动识别并渲染微博内容中的 Markdown 格式文本。

## 功能

- **自动识别** — 检测微博内容中的 Markdown 语法（标题、加粗、代码块、列表、引用、表格等）
- **实时渲染** — 监听页面动态加载，新微博自动处理
- **单条切换** — 每条渲染后的微博右上角有 `MD` 按钮，可切换原文/渲染视图
- **全局开关** — 点击扩展图标可全局启用/禁用
- **话题保留** — 微博话题标签 `#话题#` 保留为可点击链接，不会被误解析为标题
- **展开兼容** — 未展开的长微博不会被处理，展开后自动渲染

## 安装

1. 下载或 clone 本仓库
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择 `WeiboMD` 目录

## 支持的 Markdown 语法

| 语法 | 示例 |
|------|------|
| 标题 | `# H1` `## H2` `### H3` |
| 加粗 | `**粗体**` |
| 斜体 | `*斜体*` |
| 行内代码 | `` `code` `` |
| 代码块 | ` ```code``` ` |
| 无序列表 | `- item` |
| 有序列表 | `1. item` |
| 引用 | `> quote` |
| 链接 | `[text](url)` |
| 图片 | `![alt](url)` |
| 分隔线 | `---` |
| 表格 | GFM 表格语法 |

## 技术栈

- Chrome Extension Manifest V3
- [marked.js](https://github.com/markedjs/marked) — Markdown 解析
- MutationObserver — 动态内容监听
